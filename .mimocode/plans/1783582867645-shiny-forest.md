## Objectif
Zéro code procédural dans lib/ et pages/. Tout en OOP dans src/.

## Phase 2 — Migrer les 2 pages actives

- Source : `pages/docs.php` (3.8KB, thin wrapper qui require `lib/docs_sections.php`)
- Créer `src/Controller/DocsController.php`
- Ajouter `docs` au CONTROLLER_MAP dans `index.php`
- Supprimer `pages/docs.php`

### 2.2 Créer ValidateController
- Source : `pages/validate.php` (26KB, la plus grosse page active)
- Créer `src/Controller/ValidateController.php`
- Injecter les services nécessaires (WorkflowEngine, TokenService, ValidatorDataService, MailerService)
- Ajouter `validate` au CONTROLLER_MAP dans `index.php`
- Supprimer `pages/validate.php`

## Phase 3 — Absorber les 4 fichiers procedural business logic

### 3.1 admin_forms_handlers.php (21 fonctions, 35KB)
- Déplacer les handlers POST dans `AdminFormsController` ou créer `App\Forms\AdminFormHandler`
- Les 21 fonctions sont des handlers de formulaire admin (POST processing)

### 3.2 admin_forms_json.php (2 fonctions, 21KB)
- `validate_form_json()` et `format_validation_results()`
- Déplacer dans `App\Forms\FormValidationService` ou absorber dans `AdminFormsController`

### 3.3 admin_forms_samples.php (1 fonction, 17KB)

**Après chaque fichier :** supprimer l'ancien lib/ et mettre à jour les require.

## Phase 4 — Convertir les 17 render templates en classes

### 4.1 Grouper par domaine

| Groupe | Fichiers | Classe cible |
|--------|----------|--------------|
| Navigation | `render_navigation.php` (24.7K) | `App\Render\NavigationRenderer` |
| Forms | `render_form.php` (18.7K) | `App\Render\FormRenderer` |
| Errors | `render_errors.php` (10.3K) | `App\Render\ErrorRenderer` |
| LDAP | `render_ldap.php` (1.2K) | `App\Render\LdapRenderer` |
| Index | `render_index.php` (21K) | `App\Render\IndexRenderer` |
| Dashboard | `render_dashboard.php` (28.9K) | `App\Render\DashboardRenderer` |
| Monitoring | `render_monitoring.php` (36.8K) | `App\Render\MonitoringRenderer` |
| Submission | `render_submission_view.php` (39.2K) | `App\Render\SubmissionViewRenderer` |
| Backup | `render_backup.php` (19.2K) | `App\Render\BackupRenderer` |
| Install | `render_install.php` (25.5K) | `App\Render\InstallRenderer` |
| Admin Settings | `render_admin_settings.php` (36.8K) | `App\Render\AdminSettingsRenderer` |
| Admin Forms (6) | `admin_forms_render*.php` (89K total) | `App\Render\AdminFormsRenderer` |

### 4.2 Pattern par classe
Chaque classe aura :
- Un constructeur injectant les dépendances nécessaires
- Des méthodes publiques correspondant aux fonctions actuelles
- Des méthodes privées pour les helpers internes

### 4.3 Migration progressive
- Par commiter par renderer (1 renderer = 1 commit)
- Garder des wrappers globaux temporairement pour rétrocompatibilité
- Supprimer les wrappers après migration des appelants
